백내장 | 개요·시각단서·감별·관리 (반려견·수의학 veterinary canine cataract dog)
[키워드] 백내장, cataract, canine cataract, 강아지, 반려견, 수의, 동물병원, veterinary, canine, dog

## 1) 개요·핵심 요약

수정체가 혼탁해 빛이 흐려 보이는 상태로, 동공 뒤가 회백색으로 흐릿해 보이며 시야 저하가 의심될 수 있다. 사진 판독 시 동공 뒤 혼탁 여부, 반사 소실, 시각 반응 변화 등을 우선 확인한다. 주된 원인은 노령 변화, 대사 이상, 유전·염증 이력, 외상 등이다. 관리 측면에서는 환경 변경을 최소화하고 안전을 확보한다. 시력 저하 의심, 보행·계단에서의 망설임 증가, 충돌·넘어짐이 늘면 평가가 필요하다. 

## 2) 시각적 단서(사진 기반 체크리스트)

1. 전면적 또는 국소 혼탁이 동공 뒤편에서 관찰됨
2. 반사 소실 또는 약화(tapetal reflex 저하)
3. menace response 저하 또는 소실 가능
4. 렌즈 팽창 징후가 보일 수 있음(특히 대사성 원인에서)
5. 급속 진행 가능성 단서(짧은 기간 내 혼탁 범위 확대)
6. 염증 동반 가능성(전방 혼탁, 충혈 등) 

## 3) 단계별 특징·감별 포인트

- 초기 백내장(incipient): 렌즈 혼탁이 작고 국소적, 반사 보존, 시력 변화 미미 
- 비성숙(immature): 혼탁 확산, 반사 부분 소실, 기능적 시력 일부 남음 
- 성숙(mature): 전면적 혼탁, 반사 완전 소실, 시력 상실, 렌즈 팽창 가능 
- 과성숙(hypermature): 피질 액화·재흡수, 렌즈낭 주름·석회화, 핵 가라앉음, 전방 염증 동반 가능 

## 4) 임상 검사(텍스트 근거 보강용)

검안경·슬릿램프를 통한 위치·범위 평가, 안과 초음파로 후극 구조 확인, ERG로 망막 기능 평가, 안압 측정으로 염증 동반 시 변화 모니터링. 필요 시 B-scan 초음파 보조 활용. 

## 5) 보호자 안내(요약 템플릿)

- 가정 관리: 가구 재배치 최소화, 이동 동선 안전 확보 
- 내원 기준: 시력 저하 의심, 보행·계단에서 망설임 증가, 충돌·넘어짐 증가 시 평가 필요 
- 주의 사항: 급속 진행 가능성과 염증 동반 가능성 인지, 처방·재검 일정 준수 

## 6) RAG 정규화 스키마

### 6-1. 표준 증상 태그(allowed_symptoms)

전면적 혼탁 / 반사 소실 / menace response 상실 / 렌즈 팽창 / 급속 진행 가능성 / 염증 동반 가능성 

### 6-2. 검색·매칭 동의어/키워드

- 전면적 혼탁: lens opacity, total opacity, diffuse opacity
- 반사 소실: absent tapetal reflex, reflex loss
- menace response 상실: absent menace response
- 렌즈 팽창: intumescent lens, lens swelling
- 급속 진행: rapid progression, acute progression
- 염증 동반: lens-induced uveitis, phacolytic, phacoclastic 

## 7) 이미지 판독 가이드(프로시저)

1. 동공 뒤 혼탁의 범위와 위치 확인
2. 반사 소실 여부와 menace response 변화 확인
3. 렌즈 팽창·전방 염증 단서 확인
4. 급속 진행 단서나 안전 이슈가 있으면 내원 안내 문구 포함 

## 8) RAG 응답 템플릿(예시)

- 요약: 백내장 소견으로 의심되며 혼탁 범위와 반사 소실 정도를 근거로 단계 추정
- 시각 근거: 동공 뒤 혼탁과 반사 소실, menace response 변화
- 가정 관리: 환경 변경 최소화, 안전 확보
- 내원 기준: 시력 저하 의심·보행 불안·충돌 증가 시 평가 필요
