Python 3.12.14에서 테스트 **31개**, Ruff 검사·형식 확인, 의존성 검사를 수행했습니다. CSV·JSON·BOM·필수 열·잘못된 입력, 생성 성공/실패 분리, 컨텍스트 보존, 원본 corpus 보존, 도메인 점수, debug 경로, CLI 제한·다른 디렉터리 실행, 모델 설정, SDK 응답의 중단·거절·빈 내용 처리를 확인합니다.

Teacher는 모의 클라이언트이며 설치한 OpenAI SDK의 실제 응답 스키마로 테스트합니다. 예상하지 않은 검색 호출은 테스트에서 실패하도록 설정했습니다. 실제 키·개인 데이터는 사용하지 않았습니다.

검색 품질, GPT-4o 실제 생성·계정 접근, 수의학적 사실성, 인용 타당성, VLM 재학습과 과거 분류 수치 재현은 검증하지 않았습니다. dry-run 출력은 학습 데이터가 아니며, 모의 성공 출력도 배포된 생성 예시로 제공하지 않습니다.
