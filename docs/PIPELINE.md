# 파이프라인 설계와 현재 한계

[프로젝트 소개](../README.md) · [실행 안내](SETUP.md) · [데이터 형식](DATA_FORMAT.md)

준비된 진단명·증상과 로컬 문서·검색 결과를 연결해 설명형 학습 자료를 만드는 모듈입니다. 이미지 분석이나 새 진단 판정, 전체 챗봇 서비스, VLM 학습을 이 파일에서 수행하지 않습니다.

## 함수와 흐름

모든 처리 함수는 [auto_ctx.py](../auto_ctx.py)에 있습니다.

| 함수 | 역할 |
| --- | --- |
| `load_rows_from_csv`, `load_rows_from_json_dir` | 필수 열·JSON 형식 확인, 공통 입력 정규화 |
| `load_local_corpus_by_diag` | 7개 분류 이름에 맞는 로컬 문서 읽기. Unicode 파일명 비교, 원본 변경 없음 |
| `ddg_search`, `wiki_chunks` | 선택적 검색 요약·Wikipedia 본문 수집 |
| `filter_docs`, `prefer_authority`, `dedup_near_duplicates` | 길이·광고 링크·출처 점수·중복 기준 선별 |
| `build_ctx_for_row` | 입력·로컬·검색 컨텍스트 통합, 시드 보강, 번호 부여 |
| `compose_teacher_prompt` | 섹션과 근거 사용 옵션을 반영한 프롬프트 |
| `call_teacher_llm` | 환경변수 키·모델 설정, 정상 완료·내용 확인, 실패 예외 |
| `create_sft_messages` | 수집 컨텍스트로 자체 형식의 학습 대화 구성 |
| `process_rows` | 성공·preview·error 출력 분리, 행별 처리 집계 |

## 컨텍스트 선별

입력 `ctx`와 진단별 로컬 문서에 선택적 검색 결과를 더합니다. URL 문서가 없으면 저장된 진단별 시드를 하나 보강합니다. 120자 길이·광고 링크 필터 후 선호 도메인, 검색 출처, 제목의 `dog` 등을 점수화하고 URL/제목 기준 중복을 제거합니다.

문서가 부족하면 **원래 수집한 입력·로컬·검색 근거를 보존한 상태에서** 길이 조건을 60자로 완화하고 재선별합니다. 검색 API를 다시 호출하지 않습니다. 같은 선별 조건에서 상위 `k`개를 골라 번호를 붙입니다.

선호 도메인은 실제 hostname 또는 그 하위 도메인으로 확인합니다. 출처 점수는 문서의 수의학적 타당성이나 최신성 검증이 아닙니다. 시드의 URL은 저장된 참조 주소이며 실행 시 원문을 다시 가져오지 않습니다.

## 생성과 학습 대화

`use_ctx_only: true`면 컨텍스트가 지지하는 내용만 쓰고 근거 부족을 밝히도록 요청합니다. `false`면 검색 근거와 배경 지식을 구분하여 표현하도록 요청합니다. 이는 실제로 다른 프롬프트를 만드는 옵션이며, 자동 사실 검증 기능은 아닙니다. 입력 진단명·증상을 설명하고 새 진단을 추론하지 않도록 요청합니다.

`freeze_report`는 기존 입력 메타데이터로 보존하지만 별도 검증 스위치가 아닙니다. 원래 입력 객체의 진단명을 모델 출력으로 다시 덮어쓰는 기능은 없습니다. `instructions.sections`는 생성 섹션 이름에 반영합니다.

Teacher는 기존 Chat Completions 경로를 사용합니다. 정상 완료(`finish_reason: stop`)·비어 있지 않은 내용·거절 없음이 확인돼야 출력 레코드를 만듭니다. 토큰 한도·필터 등으로 중단된 출력은 오류 처리합니다. 이 구분은 [공식 API 응답 정의](https://developers.openai.com/api/reference/python/resources/chat/subresources/completions/methods/create)를 따릅니다. 생성문이 사실이고 모든 인용이 적절하다는 보장은 아닙니다.

`search`·`fetch` 메시지는 코드가 구성한 **학습용 대화**입니다. Teacher가 직접 도구를 호출한 로그가 아닙니다. 검색을 끈 경우에도 문서에 기반해 이 형식을 구성할 수 있으며 API 표준 메시지나 특정 학습기에 곧바로 호환되는 형식도 아닙니다.

## 현재 한계

- 이미지를 읽지 않고 `image_path`는 식별자에 사용합니다.
- 로컬 문서·시드의 출처와 작성 이력에는 [기존 확인 한계](DATA_SOURCES.md)가 남아 있습니다.
- 근거·인용·설명의 사실성은 프롬프트와 간단한 상태 필드로만 다루며 전문 검수나 정량 품질 검증은 아닙니다.
- 웹 검색 실패는 로컬 문서·시드로 이어질 수 있습니다. 수집 스냅샷과 최종 근거를 확인해야 합니다.
- 결과 파일은 실행마다 덮어쓰며 대규모 재시작·이어쓰기 작업 큐는 없습니다.
- 외부 검색·실제 Teacher·VLM 재학습은 이번 개선 검증에 포함하지 않았습니다.

## 2026.10.07 변경의 의미

기존 폴백 문자열을 성공 학습 레코드에서 제거하고, dry-run·실패 종료 코드·입력 확인·컨텍스트 보존·설정·테스트를 추가했습니다. 원래 졸업프로젝트의 성과와 이 공개 코드 개선을 구분합니다. 기존 생성 예시는 [별도 문서](GENERATED_EXAMPLES.md)에 보존했습니다.
